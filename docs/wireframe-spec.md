# 와이어프레임 화면 명세 (외국인 직원 급여 모듈)

대상 파일: https://www.figma.com/design/mkJ9roCfr6P9wK0681E86d/UXUI-작업-파일 (페이지 `k bank & kakao bank`)
실행 코드: `tools/figma/hp_plugin/code.js`
작업 규칙: `.claude/CLAUDE.md`

## 개념
- 케이뱅크·카카오뱅크 앱의 **이체 화면에 붙이는 모듈**. 두 은행에 같은 화면을 컬러만 바꿔 탑재한다.
- **노란 테두리와 NEW 배지 = 새로 붙는 부분.** 나머지는 기존 은행 앱 화면을 그대로 쓴다는 전제다.
- 사장님 6화면(S1~S6), 직원 2화면(E1~E2). 사장님의 5단계 여정(연결, 준비, 점검, 지급, 증명과 보상)을 따른다.

## 공통
- 프레임: 402 × 874 (파일에 이미 있는 프레임 사용, `status-bar`와 `home-indicator`는 건드리지 않음)
- 폰트: Pretendard (Regular, Medium, SemiBold, Bold)
- 색: 네이비 `#0B1F4F`(주 버튼, 강조), 잉크 `#191F28`, 회색 `#6B7684`, 연회색 `#B0B8C1`, 카드 배경 `#F2F4F6`, 노랑 `#FFE300`, 연노랑 `#FFF7C2`
- 여백: 좌우 20, 카드 패딩 16, 카드 모서리 16, 하단 버튼 높이 56
- 로컬 컴포넌트(`와이어 컴포넌트` 프레임): `nav/top`, `button/primary`, `button/secondary`, `row/kv`, `item/check`, `badge/new`

### S1 사장님 홈
- 상단: "홈" + 오른쪽 "사장님" 알약
- 이벤트 배너 자리 (회색 블록)
- **NEW 카드:** 외국인 직원 급여 / 이체하면 모국어 명세서까지 자동으로 / 직원 3명, 다음 급여일 9월 25일 / ›
- "사장님 편의" 아이콘 4칸 (거래처조회, 신용리포트, 근태관리, 더보기)
- 하단 탭바 자리

### S2 직원 등록
- 상단 바: 직원 등록 / 제목: 외국인 직원을 등록해요
- 직원 카드: 응우옌 반 A / 칩 베트남, 베트남어, E-9 / 급여 계좌 OO은행 1234
- **NEW 공제 템플릿:** 숙식비 월 300,000원 / 4대보험 자동 계산 / 서면 동의서 업로드 완료
- 사장이지 연동 카드 (토글 켜짐): 출퇴근 기록과 급여 계산값을 불러와요
- 하단 버튼: 등록 완료

### S3 급여일 미리보기
- 상단 바: 9월 급여 / 제목: 급여일까지 3일 남았어요
- 이번 달 급여 (사장이지 계산): 9,520,000원, 직원 3명
- **NEW 잔액 알림 (연노랑):** 잔액이 1,200,000원 부족해요 / 급여일 전에 사업자 운전자금으로 채울 수 있어요 / [한도 확인하기]
- 하단 버튼: 급여 보내기

### S4 이체 확인 (이체 전 점검)
- 상단 바: 이체 확인 / 제목: 3명에게 9,520,000원을 보낼게요
- 받는 사람: 응우옌 반 A 2,380,000원 / 쩐 티 B 2,420,000원 / 람 C 4,720,000원
- **NEW 경고 카드 (연노랑):** 이체 전에 확인해 주세요 / 응우옌 반 A의 숙식비 공제가 서면 동의 금액(300,000원)보다 많아요 / 판정이 아닌 참고 알림이에요
- 체크: 최저임금 확인 완료 / 명세서 함께 보내기 켜짐
- 하단 버튼 두 개: [수정하기] [그대로 보내기]

### S5 이체 완료
- 가운데 큰 체크, 9,520,000원, 3명에게 보냈어요
- **NEW 명세서 발송 카드:** 지급 확인 명세서를 보냈어요 / 응우옌 반 A 베트남어 카톡 / 쩐 티 B 베트남어 카톡 / 람 C 네팔어 카톡 / 은행이 9월 25일 14:02 지급을 확인했어요
- 하단 버튼: 확인

### S6 급여 기록
- 상단 바: 급여 기록 / 제목: 9월 급여, 모두 확인됐어요
- **NEW 열람과 대조:** 응우옌 반 A 열람과 대조 완료 / 쩐 티 B 열람과 대조 완료 / 람 C 문의 1건
- 람 C의 문의: "숙식비가 뭐예요?" / 네팔어에서 한국어로 번역됨 / [답장하기]
- **NEW 혜택 카드:** 성실 지급 12개월째 / 사업자 대출 금리 우대 대상이에요 / 혜택 보기 ›
- 하단 버튼: 기록 PDF 내려받기

### E1 카카오톡 알림 (직원)
- 카톡 배경, 상단 "‹ 케이뱅크"
- **NEW 알림톡 말풍선:** (노란 머리) Bảng lương tháng 9 đã đến / 9월 급여명세서가 도착했어요 / 2,380,000원 / 입금 확인 완료 / [명세서 보기]

### E2 모국어 명세서 (직원)
- 상단: Bảng lương tháng 9 + 언어 알약 "Tiếng Việt"
- **NEW 대조 결과:** 명세서 금액과 입금액이 같아요 (Số tiền khớp) / 은행이 9월 25일 14:02 지급을 확인했어요
- 명세 표: 기본급 2,600,000 / 숙식비 ⓘ -150,000 (연노랑 강조) / 보험료 ⓘ -70,000 / 실수령 2,380,000
- 공제 설명 (연노랑): 숙식비는 사장님이 제공한 숙소와 식사 비용이에요 (서면 동의 기준)
- 하단 버튼: 사장님에게 문의하기
